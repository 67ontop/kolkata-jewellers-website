# Kolkata Jewellers Website

This is a static website, so it can be hosted almost anywhere.

## Make It Public

1. Buy a domain such as `kolkatajewellers.com` from a domain provider.
2. Create a free Netlify or Vercel account.
3. Drag this folder into Netlify Drop, or upload it as a static project.
4. In the hosting dashboard, connect the purchased `.com` domain.
5. Follow the DNS instructions from the hosting provider.

## Files

- `index.html` controls the page content.
- `style.css` controls the design.
- `script.js` controls the mobile menu, smooth scrolling, year, and animations.
